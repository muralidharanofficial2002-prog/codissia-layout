# Download the SUBCON 2027 Figma canvas package

This branch contains the generated Figma package. Application source is unchanged from commit `3a3fccb6c70174a8c4dc30c157b596e308920ea5`.

1. Open `SUBCON-2027-Figma.zip` in this folder.
2. Click GitHub's **Download raw file** button to save the ZIP.
3. Extract it and open the included `README.md`.
4. In the Figma desktop app, use **Plugins → Development → Import plugin from manifest…**, choose `manifest.json`, and run the plugin.

The plugin creates five editable pages, 175 connected desktop/mobile prototype states, and 45 native component variants across 14 sets. The ZIP also includes an offline visual preview, import guide, and local validation report. It creates the canvas when run in Figma; it is not a binary `.fig` file. Actual Figma import/playback remains unverified.

If Figma asks for a generated plugin ID, the included guide explains how to create a development plugin and retain its Figma-generated ID.
